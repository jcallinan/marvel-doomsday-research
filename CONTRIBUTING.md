# Contributing

Everyone is welcome to contribute original, sourced research.

1. Check existing entries and issues before opening a pull request.
2. Keep PRs focused; include issue numbers, publisher and dates for comic claims, and canonical URLs for film or trailer claims.
3. Separate directly observable trailer details from interpretations and fan theories.
4. Use relative Markdown links and concise summaries written in your own words.
5. Do not submit comic scans, copyrighted video, long quotations, harassment, or uncredited AI-generated material.
6. Describe the change, sources, and uncertainties in your PR.

**Good first issues:** source a comic entry; verify a promotional video URL; improve the reading order; add a cited alternate-universe Doom; fix a broken link.
